# Tic Tac Toe — Web Technologies Project

A responsive two-player Tic Tac Toe game built using **HTML, CSS and JavaScript**.

## Features
- Two-player gameplay (X and O)
- Detects wins and draws
- Highlights the winning combination
- Keeps score across rounds
- Restart Game and Reset Score buttons
- Responsive layout for mobile and desktop

## How to run
1. Download or clone this project.
2. Open `index.html` in a web browser.
3. Play by tapping or clicking any empty square.

## Files
- `index.html` — game structure
- `style.css` — design and responsive styling
- `script.js` — game logic and score handling

## Upload to GitHub
1. Sign in to GitHub and open your repository.
2. Choose **Add file → Upload files** (on mobile, open GitHub in Chrome and select **Desktop site** if the option is missing).
3. Upload `index.html`, `style.css`, `script.js` and `README.md` from this folder.
4. Scroll down, enter a commit message such as `Add Tic Tac Toe game`, and tap **Commit changes**.

## Publish the game with GitHub Pages
1. Open your repository and go to **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait a minute and refresh the Pages section. Open the website link shown there.
